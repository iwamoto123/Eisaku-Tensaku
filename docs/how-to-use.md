# 英作文添削メーカー 使い方

生徒の答案を渡すと、添削のフィードバック資料をAIが下書きし、そのままPDFで生徒・保護者に送れるツールです。

サイト: https://eisaku-tensaku-three.vercel.app

## ログイン

登録済みのメールアドレスを入れて「ログイン用のリンクを送る」を押すと、メールが届きます。リンクを押せばログインできます。パスワードを受け取っている場合は「パスワードでログインする」からでも入れます。

アカウントがまだの方は、岩本にメールアドレスを伝えてください。こちらで作成します。

## 資料をつくる手順

1. 生徒を選ぶ（いなければトップページの下から追加する。名前・敬称・級／コースだけでOK）
2. 「新しい添削をつくる」を押す
3. 種類を選ぶ
   - ライティング … 意見論述などの答案。A4で10ページ前後の詳しい資料
   - 英訳課題 … 毎日の英訳。1問ずつ短く、A4で1〜2ページ
4. 答案を渡す。次のどちらでもOK（両方入れても大丈夫）
   - 写真やスクリーンショットをドラッグ、またはCmd+Vで貼り付け（最大8枚）
   - LINE等でテキストで送られてきた場合は「答案の本文」に貼り付け
5. 「指摘したい英語の内容」に、赤ペンを入れたい箇所を箇条書きで書く（任意）
6. 「追加で伝えたいこと」に、方針や前回からの申し送りを書く（任意）
7. 作成ボタンを押す。ライティングは3〜5分、英訳課題は1〜2分かかります

作成中は画面を開いたままにしてください。完成すると結果の画面に移ります。

## 渡し方

完成したら「PDFで保存」を押せば、そのまま生徒・保護者に送れるA4のPDFになります。LINEに画像で送りたい場合は「PNGで保存（ページ分割）」を使ってください。

内容を直したいときは「本文を編集」を押すと、資料の文章をそのまま書き換えられます。書き換えたら「保存」を押してください。元に戻したいときは「AIの生成内容に戻す」で最初の状態に戻ります。

## うまく使うコツ

- 問題用紙と答案を別々に撮った場合も、両方入れれば対応させて読みます
- 「指摘したい英語の内容」に書いた項目は必ず資料で扱われます。逆に何も書かなければ、AIが答案を読んで優先順位をつけます
- 答案の写真は、文字が読める程度に明るく撮れていれば十分です
- 過去の添削は生徒ごとに残るので、前回何を指摘したかはその生徒のページで確認できます
